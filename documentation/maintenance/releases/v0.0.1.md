# v0.0.1

npm publish workflow, Trusted Publisher CI, and workspace `nifty publish` / `nifty trust`.

## Features

- Add `nifty publish` with npm topological ordering via `nifty-publisher`
- Add `nifty trust` CLI and TOTP OTP auth for Trusted Publisher setup
- Add `publish-npm.yml` OIDC release workflow and CI tag orchestration scripts
- Add `pnpm` workspace for `@doki-land/nifty` packages
- Add `nifty bump` patch-by-default semantics
- Bootstrap default `nifty.config.ts` when the CLI starts without config
- Expose publish cache, refresh, and skipped-version reporting through NAPI
