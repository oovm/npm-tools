# v0.0.0

First public `@doki-land/nifty` workspace release: Rust crates behind Node-API, platform native packages, and the `nifty` CLI skeleton.

## Features

- Bootstrap hybrid monorepo layout under `projects/crates` and `projects/packages`
- Add `nifty-types`, `nifty-git`, `nifty-github`, `nifty-config`, `nifty-formatter`, `nifty-linter`, `nifty-updater`, and `nifty-uploader`
- Wire `nifty-napi` Node-API bindings and `@doki-land/nifty` platform packages
- Add `nifty bump` with workspace manifest discovery
- Add `nifty-uploader` for GitHub Release assets and Pages deploy
- Add `nifty-updater` dependency refresh helpers
- Add `build:napi` script and CI native artifact publishing

## Other

- Align Rust crates and npm packages on the first semver baseline ([@aster](https://github.com/aster))

- Replace `nifty-wasi` with `nifty-napi` ([@aster](https://github.com/aster))
