# v0.0.3

Workspace format and lint, updater refresh, and `@doki-land/nifty-skills`.

## Features

- Add `nifty format` via `oxc_formatter` and `cargo fmt`
- Wire `nifty lint` and `nifty update` through `nifty-napi`
- Add pnpm workspace support to `nifty-updater`
- Port `cargo cry` hygiene scans to `nifty-linter` `cargo/*` rules
- Add selective `publish --package` filter to `nifty-publisher`
- Add `@doki-land/nifty-skills` Agent Skills package
