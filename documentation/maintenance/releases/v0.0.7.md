# v0.0.7

Inline formatter style in `nifty.config`, preset cleanup, and cargo lint fixes for hybrid monorepos.

## Features

- Inline `format.style` object in `nifty.config` (no `biome.json` / `oxfmtrc.json` discovery)
- Rename primary format preset to `nifty` (`npm-tools` kept as alias, `vmz` preset retained)

## Bug Fixes

- Skip `node_modules`, `.git`, `dist`, and `.cache` in cargo workspace scanner walks
- Expand gitmoji known list with init, scaffold, ignore, brand, perf, and security emojis

## Breaking Changes

- `format.style` is an inline object, not an external config path string

## Other

- Improve `nifty commit` lint export, scan, and audit reporting ([@aster](https://github.com/aster))
