# v0.0.8

Default `typescript/large-file` workspace lint for hybrid and npm monorepos.

## Features

- Add `typescript/large-file` warning for `.ts`/`.tsx`/`.mts`/`.cts` sources over 1000 lines
- Run TypeScript large-file scans on cargo, hybrid, and npm workspace roots (alongside existing `cargo/large-file` for Rust)
