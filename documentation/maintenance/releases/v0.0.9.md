# v0.0.9

Expand Trusted Publisher native matrix and `nifty publish --placeholder`.

## Changes

- Publish native binaries for `linux-arm64` (`ubuntu-24.04-arm`) and `darwin-x64` (`macos-15-intel`) in addition to `win32-x64` / `linux-x64` / `darwin-arm64`
- Wire those platforms through `scripts/ci/publish-npm.mjs` so registry sidecars leave `0.0.0` placeholders
- Add `nifty publish --placeholder` for never-published workspace packages as `0.0.0`
- Include `darwin-x64` / `linux-arm64` in `@doki-land/nifty` optionalDependencies

## Note

`win32-arm64` is still not a Nifty sidecar package (GitHub now has `windows-11-arm`). Add when the package + napi mapping exist.
