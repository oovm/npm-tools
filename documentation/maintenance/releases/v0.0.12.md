# v0.0.12

Respect workspace `private` for publish and trust.

## Changes

- Never publish `private: true` workspace packages, even when listed in `publish.packages` or `--package`
- Skip dependents with a required (`dependencies` / `peerDependencies`) workspace dep on a private package
- Resolve `publishConfig.name` when checking registry versions (`vmz` → `@vmz/vmz`)
- `nifty trust` uses registry names for workspace packages and skips private targets from config lists

## Migration

Remove `private: true` from packages you intend to ship. Use `publish.packages` only to narrow the
non-private set, not to override `private`.
