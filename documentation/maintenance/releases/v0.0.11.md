# v0.0.11

Finish Trusted Publisher native latest policy and make `nifty publish --placeholder` usable for private workspace packages.

## Changes

- Do not fail the release when OIDC cannot `npm dist-tag` (publish already sets `latest`)
- `publish.packages` / `--package` may include `private: true` workspace packages (`private` stripped on publish)
- Honor `publishConfig.name` when staging (e.g. workspace `vmz` → `@vmz/vmz`)
- `nifty publish` loads `publish.packages` from `nifty.config.ts` (same as `nifty trust`)

## Note

`v0.0.10` only shipped `@doki-land/nifty-win32-x64` before the dist-tag gate aborted the job. Prefer this tag for the full set.
