# v0.0.2

Git history tooling, OIDC publish hardening, and native platform packages on npm only.

## Features

- Add `nifty-history` crate and expose reword, retime, and change-logs through NAPI
- Add `nifty` install-native and `scripts/ci/nifty.mjs` for CI artifact staging
- Adopt `@vmz/commander` for the `nifty` CLI
- Skip duplicate GitHub Release assets and npm versions on publish retry
- Extend `nifty-publisher` trust for pnpm workspaces

## Bug Fixes

- Inject repository metadata for npm provenance publish ([@aster](https://github.com/aster))
- Fix OIDC npm publish in CI ([@aster](https://github.com/aster))
- Parse npm trust list without broken `--json` flag ([@aster](https://github.com/aster))
- Fix block comment terminator in `install-native-artifacts.mjs` ([@aster](https://github.com/aster))

## Breaking Changes

None

## Other
