# nifty-types

Shared types and gitmoji conventions for [Nifty](https://www.npmjs.com/package/@doki-land/nifty). Hosts the known gitmoji table, subject parsing and formatting, and GitHub author maps used by `nifty-git` and `nifty-linter`.

CLI: `nifty lint` · `nifty check`
