# nifty-history

Commit history rewrite and reference changelog generation for [Nifty](https://www.npmjs.com/package/@doki-land/nifty).

| Module | CLI | Purpose |
| --- | --- | --- |
| `commit` | `nifty commit`, `nifty retime` | Object-layer message apply and timestamp spreading (gix) |
| `changelog` | `nifty change-logs` | Tag-range reference changelogs with GitHub author lookup |

Depend on `@doki-land/nifty` unless you need this crate directly.
