# nifty-napi

Node-API bindings for [Nifty](https://www.npmjs.com/package/@doki-land/nifty). Wraps the Rust crates behind the `@doki-land/nifty` CLI and the platform `@doki-land/nifty-*` packages.

This crate is a `cdylib` built with `napi-rs`, not a general-purpose library. Depend on `@doki-land/nifty` instead.
